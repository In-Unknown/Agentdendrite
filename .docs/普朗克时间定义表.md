类型说明：
- **进位**：从0开始，，也就是已经过了多少个块，满倍率归零并向高位进1，数值范围为 `0 ~ (相对上一级倍数 - 1)`。
- **序号**：从1开始，也就是当前处于哪一个块里面，满倍率归1并向高位进1，数值范围为 `1 ~ 相对上一级倍数`。
- 最大单位“虚世”无上一级，数值范围 `1 ~ ∞`。
